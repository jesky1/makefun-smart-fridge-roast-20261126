One original one-line roast of my own smart fridge: it locked the freezer for "suspicious snacking", so my 2 a.m. ice cream now counts as a security incident. Specific detail, twist at the end, reads cleanly aloud.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22.18+) writes the single line to `/output/entry.txt`. `test.mjs` checks the competition gate (1–160 characters, one line, not blank) and that two runs produce identical text:

```sh
node --test test.mjs
```
